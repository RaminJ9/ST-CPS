# ST-CPS


## Sådan kører du projektet

### Backend Projektet
1. Naviger til `Authentication` mappen og opret en fil med navnet `password.csv`.
2. Skriv dit PostgreSQL password inde i filen.
3. Der bruges standard connection indstillinger til databasen. Hvis du har ændret nogle af disse (host, port, brugernavn, databasenavn), skal du opdatere connection strengen i backend koden tilsvarende og i appen man bruger til at kører SQL databasen.
4. Opret forbindelse til din PostgreSQL database via dit foretrukne SQL program.
5. Kør backend C# projektet.

### Frontend Mappen
6. Åbn frontend mappen i Visual Studio Code.
7. Start frontend med Live Server udvidelsen.

Så kan man bruge projektet.

## How to Run

### Backend
1. Navigate to the `Authentication` folder and create a file named `password.csv`.
2. Inside the file, write your PostgreSQL password.
3. Default connection settings are used for the database. If you have changed any defaults (host, port, username, database name), update the connection string in the backend accordingly and the app you use to run the SQL database.
4. Connect to your PostgreSQL database using your preferred SQL client.
5. Run the backend C# project.

### Frontend
6. Open the frontend folder in Visual Studio Code.
7. Start the frontend using the Live Server extension.

Then the project can be used.
